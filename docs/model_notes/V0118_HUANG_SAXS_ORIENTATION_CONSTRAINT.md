# v0.1.18 Huang-SAXS orientation-constrained geometry scan

## Question answered by this version

v0.1.17 showed that the local field generated by the prescribed beta/OAF polarization source is controlled by the film-normal projection of the local interface normal. Its scan variable was the internal sinusoidal amplitude `A`, which was deliberately uncalibrated.

v0.1.18 replaces `A` as the reported control variable by

```text
sqrt(<n_ND^2>)
```

where `n_ND` is the local interface-normal component along the film normal (ND in the Huang SAXS geometry). The sinusoidal amplitude is solved internally so that each morphology realizes a requested RMS normal projection.

The electrostatic model remains

```text
D = eps0 * eps_b(r) * E + P_rel(r,t) + P_FE_frozen(r)
div(D) = 0
```

TDGL remains frozen. No switching barrier, coercive field or physical TDGL clock is introduced in this version.

## Huang source information used

Huang 2021 Supplementary Note 10 / Supplementary Fig. 13 gives the three-region lamellar thicknesses used since v0.1.16:

```text
lamellar period = 11.8 nm
beta crystal    = 5.78 nm
OAF total       = 3.02 nm = 1.51 nm per side
IAF             = 3.00 nm
```

Supplementary Fig. 13a is a 2D edge-on SAXS pattern with the X-ray beam along TD, MD vertical and ND horizontal. The source describes the sample as preferentially oriented along MD. Supplementary Fig. 1 gives independent WAXD evidence for stronger MD than TD crystal orientation.

The published material currently available to this project does **not** contain a tabulated azimuthal `I(chi)` profile, Herman orientation factor, numerical azimuthal FWHM, or a real-space lamellar-normal distribution.

## Image-derived constraint and its limit

The rasterized Supplementary Fig. 13a was inspected around the first-order SAXS lobe. Depending on the annulus/ridge extraction used to avoid the beamstop/cross and labels, the central azimuthal width is of order

```text
FWHM ~= 9-20 degrees.
```

If this width is treated only as a Gaussian-like angular scale, it corresponds to

```text
sigma_theta ~= 3.8-8.5 degrees
```

and therefore to a small-angle normal-projection scale of order `0.07-0.15`.

These numbers are image-dependent. The pseudocolor map, beamstop/cross, text overlays and lack of raw intensity values prevent a unique azimuthal distribution from being recovered. The executable scan therefore widens the interval and labels it explicitly:

```text
sqrt(<n_ND^2>) = 0.05, 0.08, 0.10, 0.12, 0.15, 0.18, 0.20
status         = PROJECT_IMAGE_DERIVED_CONSTRAINT
```

Two larger cases are retained only for sensitivity testing:

```text
sqrt(<n_ND^2>) = 0.25, 0.30
status         = PLACEHOLDER_SENSITIVITY_BOUND
```

The value `0` is the ideal tangent-interface control.

No manuscript text should state that Huang et al. directly measured `sqrt(<n_ND^2>) = 0.05-0.20`. The source only supports the qualitative orientation and the underlying raster image from which the project-level interval was estimated.

## Mapping to the v0.1.17 morphology family

The morphology remains

```text
u = x/Lx + A sin(2*pi*z/Lz).
```

For this coordinate,

```text
du/dz = (2*pi*A/Lz) cos(2*pi*z/Lz)
du/dx = 1/Lx
n_ND = (du/dz) / sqrt[(du/dz)^2 + (du/dx)^2].
```

`src/pvdf_pf/morphology/orientation_constraint.py` numerically inverts this relation for each requested `sqrt(<n_ND^2>)`. On the current 48 x 48 square cell, representative mappings are approximately

```text
RMS n_ND    equivalent A
0.05        0.0113
0.10        0.0227
0.15        0.0343
0.20        0.0464
0.25        0.0591
0.30        0.0725
```

`A` is now an implementation variable. The geometry descriptor transferred into comparisons and later calibration is the realized RMS normal projection.

## What remains fixed

The Rui 2022 same-state combined OAF+IAF generalized-Debye response remains assigned to all non-crystal cells. The beta/OAF frozen-source amplitudes are still the normalized v0.1.16 sensitivity values. OAF polarization remains spatially uniform inside each OAF region so that this version isolates orientation spread.

Absolute local fields therefore remain proportional to the underidentified phase-resolved frozen-polarization amplitudes. The quantity that can be compared across morphology cases is the normalized response

```text
E_rms / (P_scale/eps0)
```

as a function of `sqrt(<n_ND^2>)`.

## Replacement condition

The image-derived interval should be retired when one of the following becomes available for a compatible BOPVDF state:

- raw or tabulated SAXS/WAXD azimuthal `I(chi)` data;
- a numerical azimuthal FWHM or Herman orientation factor reported by the source;
- a sufficiently resolved real-space lamellar-normal distribution.

That replacement changes the input distribution/range, not the electrostatic solver.
